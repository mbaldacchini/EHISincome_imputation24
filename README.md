# EHISincome_imputation24
This repository provides additional resources for the thesis project "Household Monthly Income Imputation Strategies for the European Health Interview Survey in Luxembourg and the GHealth Project".

Only the code used is available in this repository, as _the data cannot be published_.

The repository contains the following files:
- `dataset_creation.R`: functions to generate the missing values and create the datasets
- `algorithms_functions.R`: all the algorithms used in the thesis
- `imputation_final.R`: the imputation procedure
- `needed_functions.R`: auxiliary functions
- `consistency.R`: consistency checks
